# Interactive Date Proposal Website 💌

A beautifully designed, interactive, mobile-friendly website template to ask your partner out on a date. I originally built this to ask out my girl, and I've made it open-source so anyone can use it to create a special moment for their person. 

## ✨ Features
* **The "Unclickable" No Button:** The rejection button actively dodges the user's cursor or finger, making it impossible to say no (fully optimized for mobile touchscreens).
* **Smart Calendar Validation:** Uses Flatpickr for a clean date/time selection. It actively blocks weekday selections with a custom cute error message, enforcing weekend-only dates.
* **Custom Interactive Menu:** A grid-style food selection menu that lets them pick the vibe for the date.
* **The Grand Finale:** A CSS-animated, high-contrast digital envelope that opens to reveal a customized romantic quote and the final locked-in date details.
* **Audio Feedback:** Embedded lightweight sound effects for button clicks and the final envelope reveal.

## 🚀 How to Use & Customize
1. **Fork the Repository:** Click the "Fork" button at the top right of this page to copy it to your own GitHub account.
2. **Edit the HTML:** Open `index.html` and customize the text to fit your relationship:
   * `Ctrl+F` or `Cmd+F` to find the name **Aishee** and replace it with your partner's name.
   * Modify the food array items to match their favorite foods.
   * Change the quote inside the final opened card (Step 6).
3. **Deploy for Free:** 
   * Go to your repository **Settings** > **Pages**.
   * Under "Build and deployment", set the Source to **Deploy from a branch**.
   * Select the `main` branch and save. GitHub will give you a live URL in a few minutes!
